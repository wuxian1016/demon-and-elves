# 恶魔与精灵：本地恢复与只读 MCP

两个 ZIP 都是普通 ZIP，必须同时下载完整，文件名不要改，不要混用其他版本。它们合起来才是完整交接。先对照发件方提供的两卷 SHA-256；合并恢复到一个此前不存在的新文件夹，不能覆盖原工程。相对目录：

- latest/client/ 完整微信小游戏测试源码；latest/source.sha256 是源码清单。BUILD-INDEX.json 是准确版号、历史参考和 SDK 回执。
- assets-reference/ 是原图参考，石头人的 6 张原始整页另存，**不在游戏运行目录里**。不会随本构建自带回滚；动程序前须从对照版本独立开分支。
- latest/qa/ 是离线验证；不会接真实广告、联机账户或者个人存档。依赖不随包；需要自己已有的 Node 22+、image-size@1.2.1 与 @napi-rs/canvas@0.1.100。设 NODE 与 NODE_PATH 自选本地运行时。
- tools-and-skills/ 有项目原 Skill、许可证与只读 MCP。归档内没有私有平台系统指令、访问权限、登录会话或可操作外部账户的服务。没有经核实与此版本相配的后端源码。

## 校验后恢复

1. 用可信来源的两卷摘要先做 SHA-256 检查。再从含 latest/tools/handoff.py 的卷只提取这个脚本到临时目录。
2. 用 Python 3.11+ 执行（两个 ZIP 文件顺序不限）：
       python3 handoff.py verify --stage TEST --pin faab82ab9bc6244391b505ca86331c1a64cdc6ad43790a0f774484cc9898e2e6 "第1卷.zip" "第2卷.zip"
       python3 handoff.py restore --stage TEST --pin faab82ab9bc6244391b505ca86331c1a64cdc6ad43790a0f774484cc9898e2e6 --out "新游戏目录" "第1卷.zip" "第2卷.zip"
3. 进入新游戏目录，导入 latest/client/。想只测关键入口，运行 bash latest/qa/smoke.sh --quick；想复测附带的 Mac 离线用例，运行 bash latest/qa/smoke.sh。

## 给新的 AI / Codex 配上只读入口

在恢复后的交接根目录执行以下命令，**无需安装网络依赖**；将打印结果仅合并到你自己的 MCP 配置，不覆盖原来的其他服务：

       node tools-and-skills/offline-readonly-mcp/config.cjs --codex

不加 --codex 输出常见客户端用的 JSON。脚本按你当前解包位置生成绝对路径，不需要照抄任何原电脑路径。可先运行 node tools-and-skills/offline-readonly-mcp/test.mjs，随后重开客户端，请它调用 project_status 并读 START-HERE.md；恢复包自身不会自动配置服务或把账号授权带过去。只支持有界文本读取、列表、搜索，不提供 shell、写文件、发布或转移凭据。旧 SDK 版留作对照，若另行安装及握手，仍需本地授权和验证，不应冒称已连接。
